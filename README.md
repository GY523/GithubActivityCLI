# A Simple Github Activity CLI
## Project URL

A project from [roadmap](https://roadmap.sh/projects/github-user-activity).

## Introduction
This is a CLI application written in Python that fetch a GitHub user public recent activity when given a username. It will display 10 detailed activity and a summary of recent activities.


Deep Seek and Gemini was used to generate the program based on the requirements. I compare the difference between them in terms of the structure, documentations, libraries used and the fulfillment of the requirements. Turns out code generated by Deep Seek is more modular. Both does list out recent activities in detail. However, the example output in the requirement looks more the a summary version of the recent activities. 


At last, I choose to write out the program from deep seek and modified to display a summary version of the recent activities. Which explain why the program name is called gha-dsr, it stands for Github Activity - Deep Seek Replicate.

## Setup
Clone this repository or download the gha-dsr.py

## Run the program
```
    python gha-dsr.py <username>
```
